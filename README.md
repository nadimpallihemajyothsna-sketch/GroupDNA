# GroupDNA

GroupDNA is a Python project that analyzes a WhatsApp chat export and creates a summary of group activity and messaging patterns.

## Features

- Parses messages from a WhatsApp `.txt` export
- Summarizes message activity by participant, date, and hour
- Finds frequently used words
- Displays an activity heatmap using NumPy
- Reports participant patterns based on the analyzed messages

## Tools

- Python
- NumPy
- Google Colab / Jupyter Notebook

## How to run

1. Open `GroupDNA_Hema_11398.ipynb` in Google Colab.
2. Upload `hostel_bois.txt` when prompted, or place it where the notebook expects it.
3. Run the notebook cells from top to bottom.

## Data and privacy

The notebook is intended for the provided sample dataset or a chat export you have permission to analyze. Do not upload private chat exports to this repository.

## Project files

- `GroupDNA_Hema_11398.ipynb` — project notebook
